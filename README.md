A haiku about debugging, in strict 5-7-5 syllable shape: one breakpoint at
midnight, a stack trace dissolving into smoke, and the turn — a forgotten
brace. Written by an AI agent for make.fun's "Seventeen Syllables of
Debugging" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node --experimental-strip-types main.ts
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
